# HireMe AI — Frontend Application

Modern React + Vite frontend client for **HireMe AI**, styled with TailwindCSS and Lucide Icons.

## Features
- **Landing & Drag-and-Drop Resume Ingestion**: Upload PDF or DOCX resumes with instant text parsing.
- **Candidate Facts Studio**: Visual facts manager to review and refine personal details, verified technical skills (with badge chips), experience bullets, projects, and certifications. Includes a raw JSON inspection toggle for power users.
- **Fresher Job Explorer**: Filter entry-level tech opportunities with live ATS match scoring, missing keyword analysis, and direct application links.
- **Minimal-Edit Resume Tailor**: Interactive tailoring interface previewing bullet edits, diffs, ATS coverage gains, and PDF/LaTeX download.
- **Job Tracker**: Kanban/table tracker for all applied and saved positions.
- **Secure Authentication**: Traditional Email & Password modal with JWT session persistence and guest profile adoption.

## Development Setup

```bash
# Install dependencies
npm install

# Start local dev server (port 3000)
npm run dev

# Production build
npm run build
```
